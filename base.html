Первый урок: Скелет документа

HTML (от англ. HyperText Markup Language — «язык гипертекстовой разметки») — стандартизированный язык гипертекстовой разметки документов для просмотра веб-страниц в браузере. Веб-браузеры получают HTML документ от сервера по протоколам HTTP/HTTPS или открывают с локального диска, далее интерпретируют код в интерфейс, который будет отображаться на экране монитора.

Шаг 1:
Скачайте редактор кода, например, Brackets.
Шаг 2:
Создайте папку на рабочем столе, щёлкните по ней правой кнопкой мыши и нажмите на Open as Brackets project. Перед вами открылся редактор кода.
Шаг 3:
Кликнете правой кнопкой мыши по полю слева, нажмите на Новый файл. Назовите его index.html. Вы создали файл, в котором будете прописывать структуру вебсайта.
Шаг 4:
Напишите строчку, которую вы видите на картинке (Она нужна для того, чтобы браузер понял, какой документ перед ним).
Шаг 5:
Напишите скелет документа, его вы можете увидеть на картинке.
Скелет состоит из head (головы документа) и body (тела документа). В теле документа будет проходить сам процесс создания сайта. Всё, что будет там находиться будет называться тегами.
Шаг 6:
В head (между <head> и </head>) нужно обязательно прописать: <meta-charset=”utf-8”>. (Это специальный тег о кодировке)
Также в head можно прописать заголовок страницы: <title></title> (Например, <title>Первый урок</title>)

Третий урок: Подключение CSS, основные селекторы редактирования текста

CSS (от англ. Cascading Style Sheets «каскадные таблицы стилей») — формальный язык декорирования и описания внешнего вида документа (веб-страницы), написанного с использованием языка разметки (чаще всего HTML или XHTML).

Шаг 1:
Откройте ваш проект. Создайте новый файл под названием style.css. Нажмите на Вид и выберите Vertical Split. Теперь кликните по два раза на ваши файлы (index.html и style.css). Перетащите файл style.css в Right, index.html оставьте в Left.
