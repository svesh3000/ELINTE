# ELINTE — Basics of Website Creation

An educational static website that teaches HTML and CSS from scratch.
It contains 17 lessons presented as sliders with images and explanatory text,
covering everything from the basic HTML document structure to Flexbox and pseudo-classes.

## Features

- **index.html** — main page with all lessons
- **base.html** — page with all lessons
- **html.html** — HTML tag dictionary
- **css.html** — CSS selector dictionary
- **example.html** — full website creation example

## How to Run

Just open `index.html` in your browser.

## Technologies

- HTML5
- CSS3 (Flexbox, positioning, pseudo-classes, gradients)
- JavaScript (sliders, smooth scroll)
- jQuery
